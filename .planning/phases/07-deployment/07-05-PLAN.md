# SAR Codec Quickstart

Get started with SAR image compression in under 5 minutes.

## Installation

### Option 1: pip (Recommended)

```bash
# Basic installation
pip install sarcodec

# With GPU support (ONNX Runtime CUDA)
pip install sarcodec[gpu]

# With REST API support
pip install sarcodec[api]

# Full installation (all features)
pip install sarcodec[full]
```

### Option 2: From Source

```bash
git clone https://github.com/username/sarcodec.git
cd sarcodec
pip install -e .
```

## Download Models

Download pre-trained models from GitHub Releases:

```bash
# Create models directory
mkdir -p models

# Download 8x compression model (recommended starting point)
wget https://github.com/username/sarcodec/releases/download/v1.0.0/resnet_8x.onnx -O models/resnet_8x.onnx

# Or download all models
wget https://github.com/username/sarcodec/releases/download/v1.0.0/models.zip
unzip models.zip -d models/
```

## Compress Your First Image

### Command Line

```bash
# Compress a GeoTIFF
sarcodec compress sentinel_image.tif -o compressed.npz

# Decompress back to GeoTIFF
sarcodec decompress compressed.npz -o reconstructed.tif

# View help
sarcodec --help
```

### Python API

```python
from sarcodec import SARCompressor

# Load model
compressor = SARCompressor("models/checkpoint.pth")

# Compress
latent, metadata = compressor.compress(image_array)

# Decompress
reconstructed = compressor.decompress(latent, metadata)
```

## Python Package

### Installation

```bash
# Basic (PyTorch inference)
pip install sarcodec

# With ONNX Runtime GPU
pip install sarcodec[gpu]

# With API server
pip install sarcodec[api]

# Development
pip install sarcodec[dev]
```

### Basic Usage

```python
from sarcodec import SARCompressor, read_geotiff, write_geotiff

# Load compressor with checkpoint
compressor = SARCompressor(
    "path/to/checkpoint.pth",
    device="cuda",  # or "cpu"
    batch_size=16,  # tiles processed in parallel
    overlap=64,     # tile overlap for seamless reconstruction
)

# Read GeoTIFF
image, metadata = read_geotiff("input.tif")

# Compress
latent, tile_metadata = compressor.compress(image)

# Save compressed
compressor.save_compressed(latent, tile_metadata, "compressed.npz")

# Decompress
reconstructed = compressor.decompress(latent, tile_metadata)

# Write GeoTIFF with original metadata
write_geotiff(reconstructed, metadata, "output.tif")
```

### Batch Processing

```python
from pathlib import Path

# Process all TIFFs in directory
for tif_path in Path("input_dir").glob("*.tif"):
    image, meta = read_geotiff(tif_path)
    latent, tile_meta = compressor.compress(image)
    compressor.save_compressed(
        latent, tile_meta,
        f"output_dir/{tif_path.stem}.npz"
    )
```

## Docker Deployment

### Quick Start

```bash
# Pull image
docker pull ghcr.io/username/sarcodec:latest

# Or build locally
docker build -t sarcodec .

# Run CLI (mount your data)
docker run -v $(pwd)/data:/data sarcodec compress /data/input.tif /data/output.npz

# Run API server with GPU
docker run -p 8000:8000 --gpus all sarcodec --serve
```

### Docker Compose

```bash
# Start API server
docker compose up -d

# View logs
docker compose logs -f

# Stop
docker compose down
```

### Volume Mounts

| Mount | Purpose |
|-------|---------|
| `/app/models` | Model checkpoints (required) |
| `/data` | Input/output data |

```bash
docker run \
  -v $(pwd)/models:/app/models:ro \
  -v $(pwd)/data:/data \
  sarcodec compress /data/input.tif /data/output.npz
```

### Environment Variables

| Variable | Default | Description |
|----------|---------|-------------|
| `SARCODEC_CHECKPOINT_DIR` | `/app/models` | Model directory |
| `SARCODEC_HOST` | `0.0.0.0` | API bind address |
| `SARCODEC_PORT` | `8000` | API port |
| `CUDA_VISIBLE_DEVICES` | (all) | GPU selection |

## ONNX Export

Export models for deployment without PyTorch:

```bash
# Export single model
python scripts/export_onnx.py checkpoint.pth output_dir/

# Export all models
python scripts/export_onnx.py --all models/onnx/
```

### ONNX Runtime Inference

```python
import onnxruntime as ort
import numpy as np

# Load encoder/decoder
encoder = ort.InferenceSession("encoder.onnx", providers=["CUDAExecutionProvider"])
decoder = ort.InferenceSession("decoder.onnx", providers=["CUDAExecutionProvider"])

# Encode (raw SAR linear values -> latent)
latent = encoder.run(None, {"input": image})[0]

# Decode (latent -> raw SAR linear values)
reconstructed = decoder.run(None, {"latent": latent})[0]
```

### ONNX Files

| File | Purpose | Input | Output |
|------|---------|-------|--------|
| `encoder.onnx` | Compression | (B,1,256,256) float32 | (B,C,16,16) float32 |
| `decoder.onnx` | Decompression | (B,C,16,16) float32 | (B,1,256,256) float32 |
| `metadata.json` | Model config | - | vmin, vmax, channels |

import requests

    )
    with open("compressed.npz", "wb") as out:
        out.write(resp.content)

## Performance Tuning

### GPU Memory

```python
# Reduce batch size if OOM
compressor = SARCompressor(checkpoint, batch_size=4)

# Or set via environment
export CUDA_VISIBLE_DEVICES=0
```

### Large Images

For images > 10000x10000 pixels:

```python
# Increase overlap for better quality at tile boundaries
compressor = SARCompressor(checkpoint, overlap=128)
```

### Inference Speed

| Setting | Impact |
|---------|--------|
| `batch_size` | Higher = faster (limited by VRAM) |
| `overlap` | Lower = faster (may show seams) |
| GPU vs CPU | GPU is 10-50x faster |
| ONNX Runtime | 20-30% faster than PyTorch |

# REST API Reference

Base URL: `http://localhost:8000` (or your deployment URL)

## Authentication

No authentication required. The API is designed for local/internal use.

---

## Endpoints

### GET /health

Health check endpoint.

**Response:**
```json
{
  "status": "healthy",
  "version": "1.0.0",
  "models_loaded": ["4x", "8x", "16x"],
  "device": "cuda",
  "cuda_available": true
}
```

---

### POST /encode

Compress a GeoTIFF image to latent representation.

**Request:**
- Content-Type: `multipart/form-data`
- Body: `file` (GeoTIFF file)
- Query params:
  - `model`: Model variant (`4x`, `8x`, `16x`). Default: `8x`

**Response:**
- Content-Type: `application/octet-stream`
- Body: NPZ file containing:
  - `latent`: Compressed representation
  - `metadata`: JSON with geo_metadata and tile_metadata

**Headers:**
- `X-Processing-Time-Ms`: Processing time in milliseconds

**Example:**
```bash
curl -X POST "http://localhost:8000/encode?model=8x" \
  -F "file=@input.tif" \
  -o compressed.npz
```

**Errors:**
- `400`: Invalid file type (not GeoTIFF)
- `404`: Model not loaded
- `500`: Processing error

---

### POST /decode

Decompress NPZ to GeoTIFF image.

**Request:**
- Content-Type: `multipart/form-data`
- Body: `file` (NPZ file from /encode)
- Query params:
  - `model`: Model variant. Default: `8x`

**Response:**
- Content-Type: `image/tiff`
- Body: Reconstructed GeoTIFF

**Example:**
```bash
curl -X POST "http://localhost:8000/decode?model=8x" \
  -F "file=@compressed.npz" \
  -o reconstructed.tif
```

---

### POST /compress

Alias for `/encode`. Same parameters and response.

### POST /decompress

Alias for `/decode`. Same parameters and response.

---

## OpenAPI

Interactive documentation available at `/docs` (Swagger UI).

OpenAPI schema at `/openapi.json`.

---

## Error Responses

All errors return JSON:

```json
{
  "detail": "Error message here"
}
```

| Code | Meaning |
|------|---------|
| 400 | Bad request (invalid file, missing params) |
| 404 | Resource not found (model not loaded) |
| 413 | File too large |
| 500 | Internal server error |

# Create synthetic SAR data (similar to real SAR statistics)
np.random.seed(42)

# Base structure (smooth regions)
y, x = np.mgrid[0:512, 0:512].astype(np.float32)
base = 0.3 + 0.4 * (np.sin(x / 50) * np.sin(y / 50) + 1) / 2

# Add multiplicative speckle noise (SAR characteristic)
speckle = np.random.gamma(1, 1, (512, 512)).astype(np.float32)
synthetic_sar = 50 + 150 * base * speckle  # Linear intensity values

print(f"Synthetic SAR shape: {synthetic_sar.shape}")
print(f"Value range: [{synthetic_sar.min():.1f}, {synthetic_sar.max():.1f}]")

# Visualize
fig, ax = plt.subplots(1, 1, figsize=(8, 8))
im = ax.imshow(10 * np.log10(synthetic_sar), cmap='gray')
ax.set_title("Synthetic SAR Image (dB scale)")
plt.colorbar(im, ax=ax, label="dB")
plt.show()
```

mse = np.mean((reconstructed - synthetic_sar) ** 2)
