**src/export/wrapper.py:**
Create `SARAutoencoderWithPreprocess(nn.Module)` that:
1. Takes encoder and decoder from existing autoencoder
2. Registers vmin, vmax, noise_floor as buffers (so they export to ONNX)
3. Implements `preprocess()` method: clamp to noise_floor, convert to dB, clip to [vmin, vmax], normalize to [0,1]
4. Implements `inverse_preprocess()` method: denormalize, convert from dB to linear
5. Implements `encode(x)` that applies preprocess then encoder
6. Implements `decode(z)` that applies decoder then inverse_preprocess
7. Implements `forward(x)` for full encode-decode round-trip

Use torch operations only (no numpy) for ONNX compatibility:
- `torch.clamp()` for clamping
- `torch.log10()` for dB conversion
- `torch.pow(10.0, x/10.0)` for inverse dB

Add `@classmethod from_checkpoint(cls, checkpoint_path, device='cpu')` factory method that:
1. Loads checkpoint
2. Extracts vmin/vmax from config['preprocessing_params']
3. Instantiates ResNetAutoencoder with correct latent_channels/base_channels
4. Loads state dict
5. Returns wrapped model in eval mode
  </action>

<task type="auto">
  <name>Task 2: Create ONNX export utilities with validation</name>
  <files>src/export/onnx_export.py</files>
  <action>
Create `src/export/onnx_export.py` with ONNX export and validation functions.

**Functions to implement:**

1. `export_encoder_onnx(model, output_path, example_input=None, opset_version=20)`:
   - Exports the encoder part (raw SAR -> latent)
   - Uses `torch.onnx.export(dynamo=True)` per RESEARCH.md
   - Dynamic batch dimension via `torch.export.Dim("batch", min=1, max=256)`
   - Input name: "input", output name: "latent"
   - If example_input is None, create `torch.randn(2, 1, 256, 256)` (batch>1 per pitfall #1)
   - Call `onnx_program.optimize()` before saving

2. `export_decoder_onnx(model, output_path, latent_channels, example_input=None, opset_version=20)`:
   - Exports the decoder part (latent -> raw SAR)
   - Same dynamic batch approach
   - Input name: "latent", output name: "output"
   - example_input should match latent shape: `(2, latent_channels, 16, 16)`

3. `validate_onnx_model(onnx_path, pytorch_model, example_input, atol=1e-5)`:
   - Load ONNX model with `onnxruntime.InferenceSession`
   - Use CPUExecutionProvider for validation
   - Run same input through PyTorch model (with torch.no_grad())
   - Compare outputs with `np.allclose(pytorch_out, onnx_out, atol=atol)`
   - Return dict with: `{"valid": bool, "max_diff": float, "mean_diff": float}`

4. `export_full_model(checkpoint_path, output_dir, validate=True)`:
   - High-level function that:
   - Loads model via SARAutoencoderWithPreprocess.from_checkpoint()
   - Creates output directory
   - Exports encoder ONNX to `{output_dir}/encoder.onnx`
   - Exports decoder ONNX to `{output_dir}/decoder.onnx`
   - Validates both if validate=True
   - Saves metadata JSON: `{latent_channels, base_channels, vmin, vmax, export_date}`
   - Returns validation results

**Error handling:**
- Catch ONNX export errors and provide clear messages
- Catch ONNX Runtime import errors (suggest pip install onnxruntime)

  <action>
Create `scripts/export_onnx.py` CLI script for exporting models to ONNX.

**CLI interface:**
```
python scripts/export_onnx.py CHECKPOINT_PATH OUTPUT_DIR [OPTIONS]
python scripts/export_onnx.py --all OUTPUT_DIR  # Export all 3 ResNet models
```

**Arguments:**
- `checkpoint`: Path to checkpoint file (or --all for batch export)
- `output`: Output directory for ONNX files
- `--no-validate`: Skip validation step
- `--opset`: ONNX opset version (default: 20)
- `--all`: Export all 3 ResNet checkpoints from notebooks/checkpoints/

**Implementation:**
1. Use argparse for CLI
2. Use rich.console for colored output and progress
3. For single checkpoint:
   - Call export_full_model()
   - Print validation results with colors (green=pass, red=fail)
   - Print file sizes and paths
4. For --all mode:
   - Find all ResNet checkpoints (pattern: resnet_c*_b64_cr*x_*/best.pth)
   - Export each to {output_dir}/{model_name}/ subdirectory
   - Print summary table at end

**Output structure for --all:**
```
output_dir/
  resnet_4x/
    encoder.onnx
    decoder.onnx
    metadata.json
  resnet_8x/
    ...

    ...
```

```
python scripts/export_onnx.py --all models/onnx/
```
