**Researched:** 2026-01-29

**Confidence:** HIGH

## Summary

Phase 6.1 addresses the apples-to-oranges comparison discovered in Phase 6: autoencoder "16x compression" (geometric latent reduction) versus JPEG-2000 "16x compression" (actual file size ratio). The solution is to calculate the **actual bits-per-pixel (BPP)** for quantized autoencoder latents using entropy estimation, then compare JPEG-2000 at the same bitrate.

The standard approach in learned image compression literature (Balle et al.) is:
1. **Quantize latent representation** to discrete levels (e.g., 8-bit = 256 levels)
2. **Estimate entropy** of the quantized distribution using histogram-based methods
3. **Calculate BPP** as total_bits / num_input_pixels
4. **Compare codecs** at matched bitrates on rate-distortion curves

Key insight: Entropy of quantized latent provides a theoretical lower bound on bits needed for lossless coding. This is the standard metric used in learned compression papers for fair comparison.

**Primary recommendation:** Implement per-channel entropy estimation on 8-bit quantized latents using scipy.stats.entropy with base=2 (bits). Generate JPEG-2000 R-D curve with 20+ quality points, interpolate to match autoencoder BPP, update report.

### Pattern 1: Per-Channel Entropy Estimation
**What:** Calculate entropy separately for each latent channel, sum for total bits
**When to use:** Latent channels have different distributions (verified in Phase 4)
**Example:**
```python
# Source: scipy.stats.entropy documentation + learned compression literature
from scipy.stats import entropy
import numpy as np

def estimate_latent_entropy(
    latent: np.ndarray,
    n_bins: int = 256,
    return_per_channel: bool = False
) -> dict:
    """
    Estimate entropy of quantized latent representation.

    Args:
        latent: Latent tensor of shape (B, C, H, W) or (C, H, W)
        n_bins: Number of quantization levels (256 for 8-bit)
        return_per_channel: Return per-channel breakdown

    Returns:
        Dict with total_bits, bpp, and optionally per_channel_bits
    """
    if latent.ndim == 3:
        latent = latent[np.newaxis, ...]  # Add batch dim

    B, C, H, W = latent.shape
    input_pixels = 256 * 256  # Original image size (fixed for this project)

    # Quantize to n_bins levels per channel
    # Use per-channel min/max for quantization range
    total_bits = 0
    channel_bits = []

    for c in range(C):
        channel_data = latent[:, c, :, :].flatten()

        # Per-channel quantization range
        vmin, vmax = channel_data.min(), channel_data.max()

        # Quantize to [0, n_bins-1]
        if vmax > vmin:
            quantized = np.floor((channel_data - vmin) / (vmax - vmin) * (n_bins - 1))
            quantized = np.clip(quantized, 0, n_bins - 1).astype(int)
        else:
            quantized = np.zeros_like(channel_data, dtype=int)

        # Compute histogram (probability distribution)
        hist, _ = np.histogram(quantized, bins=n_bins, range=(0, n_bins))
        prob = hist / hist.sum()
        prob = prob[prob > 0]  # Remove zeros for log

        # Entropy in bits (base=2)
        channel_entropy = entropy(prob, base=2)  # bits per symbol
        channel_total_bits = channel_entropy * len(channel_data)

        total_bits += channel_total_bits
        channel_bits.append(channel_total_bits)

    # Add overhead for storing quantization parameters (min/max per channel)
    # 32-bit float * 2 params * C channels = 64*C bits overhead
    overhead_bits = 64 * C
    total_bits += overhead_bits

    # BPP relative to original image
    bpp = total_bits / (B * input_pixels)

    result = {
        'total_bits': total_bits,
        'bpp': bpp,
        'overhead_bits': overhead_bits,
        'n_channels': C,
        'n_samples': B,
    }

    if return_per_channel:
        result['channel_bits'] = channel_bits
        result['channel_entropy'] = [b / (B * H * W) for b in channel_bits]

    return result
```

### Pattern 2: JPEG-2000 Fine-Grained Quality Sweep
**What:** Generate R-D curve with 20+ quality points for smooth interpolation
**When to use:** Creating reference R-D curve for bitrate matching
**Example:**
```python
# Source: Existing CodecEvaluator + extension
def generate_jpeg2000_rd_curve(
    images: list,
    quality_range: tuple = (1, 1000),
    n_points: int = 25
) -> pd.DataFrame:
    """
    Generate fine-grained JPEG-2000 rate-distortion data.

    Args:
        images: List of test images (float32, [0,1])
        quality_range: Min/max quality parameter (1=max compression, 1000=lossless)
        n_points: Number of quality levels to evaluate

    Returns:
        DataFrame with quality, bpp, psnr, ssim columns
    """
    from src.evaluation.codec_baselines import JPEG2000Codec
    from src.evaluation.metrics import SARMetrics

    codec = JPEG2000Codec()

    # Generate quality levels (log-spaced for better coverage)
    qualities = np.logspace(
        np.log10(quality_range[0]),
        np.log10(quality_range[1]),
        n_points
    ).astype(int)
    qualities = np.unique(qualities)  # Remove duplicates

    rd_data = []

    for quality in qualities:
        psnr_values, ssim_values, bpp_values = [], [], []

        for img in images:
            encoded = codec.encode(img, quality)
            decoded = codec.decode(encoded)

            # BPP = encoded_bits / input_pixels
            encoded_bits = len(encoded) * 8
            input_pixels = img.shape[0] * img.shape[1]
            bpp = encoded_bits / input_pixels

            psnr = SARMetrics.psnr(img, decoded)
            ssim = SARMetrics.ssim(img, decoded)

            psnr_values.append(psnr)
            ssim_values.append(ssim)
            bpp_values.append(bpp)

        rd_data.append({
            'quality': quality,
            'bpp': np.mean(bpp_values),
            'bpp_std': np.std(bpp_values),
            'psnr': np.mean(psnr_values),
            'psnr_std': np.std(psnr_values),
            'ssim': np.mean(ssim_values),
            'ssim_std': np.std(ssim_values),
        })

    return pd.DataFrame(rd_data)
```

### Pattern 3: Bitrate-Matched Comparison
**What:** Find JPEG-2000 quality that achieves same BPP as autoencoder
**When to use:** Fair comparison at matched bitrates
**Example:**
```python
# Source: Standard interpolation approach
from scipy.interpolate import interp1d

def find_matched_quality(
    rd_curve: pd.DataFrame,
    target_bpp: float
) -> dict:
    """
    Interpolate R-D curve to find quality at target BPP.

    Args:
        rd_curve: DataFrame with bpp, psnr, ssim columns
        target_bpp: Target bits-per-pixel

    Returns:
        Dict with interpolated psnr, ssim at target_bpp
    """
    # Sort by BPP
    rd_curve = rd_curve.sort_values('bpp')

    # Check if target is within range
    if target_bpp < rd_curve['bpp'].min() or target_bpp > rd_curve['bpp'].max():
        return {'psnr': np.nan, 'ssim': np.nan, 'extrapolated': True}

    # Interpolate
    psnr_interp = interp1d(rd_curve['bpp'], rd_curve['psnr'], kind='linear')
    ssim_interp = interp1d(rd_curve['bpp'], rd_curve['ssim'], kind='linear')

    return {
        'bpp': target_bpp,
        'psnr': float(psnr_interp(target_bpp)),
        'ssim': float(ssim_interp(target_bpp)),
        'extrapolated': False,
    }
```

### Pattern 4: Quality Metric Decision (Claude's Discretion)
**What:** Whether to decode from quantized latent for quality metrics
**Recommendation:** Decode from quantized latent
**Rationale:**
- The entropy estimate assumes the quantized values are stored
- Quality metrics should reflect what's actually recoverable from the bitstream
- Quantization degradation IS the compression cost - hiding it would be unfair

```python
def evaluate_with_quantization(model, image, n_bins=256):
    """
    Evaluate autoencoder with explicit quantization.

    The quality metrics use the reconstruction from QUANTIZED latent,
    matching what would actually be decoded from a bitstream.
    """
    # Encode
    latent = model.encode(image)

    # Quantize (per-channel)
    quantized = quantize_latent(latent, n_bins)

    # Dequantize (scale back to original range)
    dequantized = dequantize_latent(quantized, latent.min(), latent.max())

    # Decode from quantized representation
    reconstruction = model.decode(dequantized)

    # Compute metrics on quantized reconstruction
    metrics = compute_all_metrics(image, reconstruction)

    return metrics, quantized
```

### Anti-Patterns to Avoid
- **Using geometric compression ratio as BPP:** "16x" latent reduction != 2 BPP; must calculate actual entropy
- **Global quantization range:** Per-channel ranges preserve more precision (different channels have different value distributions)
- **Ignoring quantization overhead:** Must include cost of storing min/max per channel
- **Comparing at mismatched bitrates:** Always verify BPP values match within tolerance (e.g., +/- 10%)
- **Measuring quality from unquantized latent:** Entropy assumes quantized storage; quality should match

## Common Pitfalls

### Pitfall 1: Confusing Latent Size with Bitrate
**What goes wrong:** Assuming 16x16x16 float32 latent = 2 BPP (32 bits / 16 = 2)
**Why it happens:** Geometric reduction looks like compression ratio
**How to avoid:** Always calculate actual entropy; quantized values compress further
**Warning signs:** BPP values that are exact powers of 2 or suspiciously round

### Pitfall 2: Global Quantization Range
**What goes wrong:** All channels quantized to same [global_min, global_max]
**Why it happens:** Seems simpler than per-channel
**How to avoid:** Calculate min/max per channel; latent channels have different distributions
**Warning signs:** Some channels use only a few quantization levels

### Pitfall 3: Ignoring Quantization in Quality Metrics
**What goes wrong:** Measuring PSNR from unquantized latent but reporting entropy-based BPP
**Why it happens:** Quantization step seems separate from quality evaluation
**How to avoid:** Decode from quantized latent; quality must match assumed bitrate
**Warning signs:** Quality seems "too good" for the reported BPP

### Pitfall 4: Insufficient JPEG-2000 Quality Points
**What goes wrong:** R-D curve is jagged, interpolation is unreliable
**Why it happens:** Using only 3-5 quality levels
**How to avoid:** Use 20-30 quality points, log-spaced across range
**Warning signs:** Large jumps in BPP between adjacent quality levels

### Pitfall 5: 8-bit vs Float32 Comparison Residue
**What goes wrong:** Still comparing against JPEG-2000's 8-bit reconstruction
**Why it happens:** Phase 6 comparison was on 8-bit data
**How to avoid:** Quantize BOTH to same precision OR document the difference clearly
**Warning signs:** JPEG-2000 still shows unrealistically high PSNR (>45 dB)

### Pitfall 6: Forgetting Overhead Bits
**What goes wrong:** BPP underestimated by ignoring side information
**Why it happens:** Only counting entropy bits, not metadata
**How to avoid:** Add overhead for: min/max per channel, latent dimensions, any hyperparameters
**Warning signs:** Autoencoder BPP seems impossibly low

### Quantization and Dequantization
```python
# Source: Standard uniform quantization
def quantize(x: np.ndarray, n_bins: int = 256,
             vmin: float = None, vmax: float = None) -> tuple:
    """Quantize array to n_bins levels."""
    if vmin is None:
        vmin = x.min()
    if vmax is None:
        vmax = x.max()

    if vmax <= vmin:
        return np.zeros_like(x, dtype=np.uint8), vmin, vmax

    # Scale to [0, n_bins-1]
    x_scaled = (x - vmin) / (vmax - vmin)
    x_quantized = np.floor(x_scaled * (n_bins - 1)).astype(np.uint8)
    x_quantized = np.clip(x_quantized, 0, n_bins - 1)

    return x_quantized, vmin, vmax

def dequantize(x_q: np.ndarray, vmin: float, vmax: float,
               n_bins: int = 256) -> np.ndarray:
    """Dequantize back to original range."""
    x_float = x_q.astype(np.float32) / (n_bins - 1)
    return x_float * (vmax - vmin) + vmin
```

### R-D Curve Plotting
```python
# Source: Matplotlib best practices
import matplotlib.pyplot as plt

def plot_rd_curves(ae_points: list, codec_rd: pd.DataFrame,
                   output_path: str, metric: str = 'psnr'):
    """
    Plot rate-distortion curves with autoencoder points.

    Args:
        ae_points: List of dicts with 'name', 'bpp', 'psnr', 'ssim'
        codec_rd: DataFrame with codec R-D curve
        output_path: Save path
        metric: 'psnr' or 'ssim'
    """
    fig, ax = plt.subplots(figsize=(10, 6))

    # Plot JPEG-2000 curve (continuous)
    ax.plot(codec_rd['bpp'], codec_rd[metric],
            'o-', color='gray', label='JPEG-2000',
            linewidth=2, markersize=4)
    ax.fill_between(
        codec_rd['bpp'],
        codec_rd[metric] - codec_rd[f'{metric}_std'],
        codec_rd[metric] + codec_rd[f'{metric}_std'],
        alpha=0.2, color='gray'
    )

    # Plot autoencoder points
    colors = {'resnet': 'tab:orange', 'baseline': 'tab:blue'}
    markers = {'resnet': 's', 'baseline': 'o'}

    for point in ae_points:
        name = point['name'].split('_')[0]  # 'resnet' or 'baseline'
        ax.scatter(point['bpp'], point[metric],
                   c=colors.get(name, 'tab:green'),
                   marker=markers.get(name, '^'),
                   s=100, label=point['name'], zorder=5)
        ax.annotate(
            point['name'].replace('_', ' '),
            (point['bpp'], point[metric]),
            textcoords='offset points', xytext=(5, 5),
            fontsize=8
        )

    ax.set_xlabel('Bits Per Pixel (BPP)')
    ax.set_ylabel('PSNR (dB)' if metric == 'psnr' else 'SSIM')
    ax.set_title('Rate-Distortion: Bitrate-Matched Comparison')
    ax.legend(loc='lower right')
    ax.grid(True, alpha=0.3)

    plt.tight_layout()
    plt.savefig(output_path, dpi=300)
    plt.close()
```

## Open Questions

   - What we know: Entropy gives theoretical minimum; practical coding adds ~1-5% overhead
   - What's unclear: Exact overhead for this data distribution
   - Recommendation: Report entropy as "achievable BPP" with note that practical coding adds small overhead

2. **Quantization Bit Depth Selection**
   - What we know: User decision is 8-bit (256 levels)

   - What's unclear: Whether to use 8-bit for both or find float32 codec
