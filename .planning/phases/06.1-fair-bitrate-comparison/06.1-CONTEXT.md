<decisions>
## Implementation Decisions

### Bitrate Calculation Method
- Use entropy estimation to calculate theoretical minimum bits for quantized latent
- Calculate entropy per-channel (not global) since channels may have different distributions
- Bin count matches quantization levels (256 bins for 8-bit quantization)
- Report both bits-per-pixel (BPP) AND total bits
- Include overhead for storing quantization parameters (min/max per channel)
- Calculate both per-image entropy (for statistics) AND aggregate across test set (for R-D curve)

### Comparison Approach
- Match JPEG-2000 to autoencoder's bitrate (calculate AE's actual BPP, configure JPEG-2000 to match)
- Create full R-D curve with 20+ JPEG-2000 quality points
- Generate R-D curves for both PSNR and SSIM metrics
- New bitrate-matched comparison replaces the 8-bit quantization results

### Quantization Strategy
- Use 8-bit quantization (256 levels) for autoencoder latent
- Determine quantization range per-channel (each channel gets its own min/max)

### Report Integration
- Replace Phase 6 comparison in existing report with bitrate-matched comparison
- Keep original executive summary, add "Updated Analysis" section with new conclusions
- Generate new R-D figures to replace existing ones
- Focus conclusion on compression efficiency (quality at same bitrate)
- Include detailed methodology section explaining entropy calculation, quantization, and bitrate matching

### Claude's Discretion
- Whether to decode from quantized latent or use original latent for quality metrics
- Whether to report quantization degradation (if significant)
- Exact figure formatting and layout

</decisions>

## Specific Ideas

- The goal is to show: "At the same number of bits, which method achieves better quality?"
- Should make it clear that previous "compression ratio" comparison was apples-to-oranges
- Entropy estimation is standard in learned image compression literature (Ballé et al.)
