## Updated Analysis: Bitrate-Matched Comparison (Phase 6.1)

### Why the Original Comparison Was Unfair

The original Phase 6 comparison used "compression ratio" to compare autoencoders and JPEG-2000:
- **Autoencoders:** 16x = geometric latent reduction (256x256x1 -> 16x16x16)
- **JPEG-2000:** 16x = actual file size ratio with entropy coding

This is an apples-to-oranges comparison because:
1. Geometric ratio ignores latent redundancy (autoencoders don't use entropy coding)
2. JPEG-2000's "16x" includes sophisticated entropy coding
3. At "16x", JPEG-2000 uses ~2 BPP while autoencoder float32 latent uses ~2 BPP geometrically but stores much more information

### Methodology: Entropy-Based Bitrate Calculation

To enable fair comparison, we calculate the **actual bits-per-pixel (BPP)** for autoencoder latents:

1. **Quantize latent** to 8-bit (256 levels) per channel
2. **Estimate Shannon entropy** of quantized distribution using histogram
3. **Calculate BPP** = total_entropy_bits / input_pixels
4. **Include overhead** for storing quantization parameters (min/max per channel)

This gives the theoretical minimum bits needed to losslessly code the quantized latent - the standard metric used in learned image compression literature (Balle et al.).
