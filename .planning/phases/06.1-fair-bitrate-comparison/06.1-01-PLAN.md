<task type="auto">
  <name>Task 1: Implement quantization and entropy estimation module</name>
  <files>src/evaluation/bitrate.py</files>
  <action>
Create `src/evaluation/bitrate.py` with the following functions:

1. **quantize_latent(latent, n_bins=256)** -> Tuple[np.ndarray, List[Tuple[float, float]]]
   - Input: latent tensor shape (B, C, H, W) or (C, H, W), float32
   - Per-channel quantization: compute min/max for each channel separately
   - Scale each channel to [0, n_bins-1] using: floor((x - vmin) / (vmax - vmin) * (n_bins - 1))
   - Return: (quantized uint8 array, list of (vmin, vmax) per channel)
   - Handle edge case: if vmax == vmin, return zeros

2. **dequantize_latent(quantized, ranges, n_bins=256)** -> np.ndarray
   - Input: quantized uint8 array, list of (vmin, vmax) ranges
   - Inverse: x_float = quantized / (n_bins - 1) * (vmax - vmin) + vmin
   - Return: float32 array in original value range

3. **estimate_channel_entropy(channel_data, n_bins=256)** -> float
   - Input: flattened channel data (already quantized to [0, n_bins-1])
   - Compute histogram with n_bins bins, range [0, n_bins)
   - Normalize to probability distribution
   - Use scipy.stats.entropy(prob, base=2) for bits per symbol
   - Return: entropy in bits per symbol

4. **estimate_latent_entropy(latent, n_bins=256, return_per_channel=False)** -> dict
   - Input: latent tensor (B, C, H, W) or (C, H, W)
   - Quantize latent using quantize_latent
   - For each channel: compute entropy using estimate_channel_entropy
   - Sum channel entropies * channel_samples for total bits
   - Add overhead: 64 * C bits (32-bit float * 2 params * C channels for min/max)
   - Return dict with:
     - 'total_bits': sum of channel bits + overhead
     - 'bpp': total_bits / (B * 256 * 256) for input image size
     - 'overhead_bits': 64 * C
     - 'n_channels': C
     - 'n_samples': B
     - 'channel_entropy': list of bits/symbol per channel (if return_per_channel)
     - 'channel_bits': list of total bits per channel (if return_per_channel)

5. **compute_latent_bpp(latent, n_bins=256, input_shape=(256, 256))** -> float
   - Convenience function: returns just the BPP value
   - Calls estimate_latent_entropy and extracts bpp

Include comprehensive docstrings following numpy style.
