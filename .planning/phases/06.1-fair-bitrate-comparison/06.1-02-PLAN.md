  <files>scripts/run_bitrate_matched_evaluation.py</files>
  <action>
Create `scripts/run_bitrate_matched_evaluation.py` with the following structure:

**Imports and Setup:**
```python
#!/usr/bin/env python3
"""
Bitrate-matched evaluation: Compare autoencoders vs JPEG-2000 at equivalent BPP.

This script:
1. Loads all 6 autoencoder checkpoints
2. Extracts latents and computes actual BPP via entropy estimation
3. Generates fine-grained JPEG-2000 R-D curve (25 quality points)
4. Interpolates JPEG-2000 metrics at autoencoder BPP values
5. Produces fair comparison figures and data

Usage:
    python scripts/run_bitrate_matched_evaluation.py --output-dir reports/bitrate_matched
"""
```

**Helper Functions (reuse from run_evaluation_sweep.py):**
- `discover_checkpoints()` - Find all 6 autoencoder checkpoints
- `load_model_from_checkpoint()` - Load model with correct architecture
- `get_compression_ratio_from_name()` - Extract ratio from name

**New Functions:**

1. **evaluate_autoencoder_bpp(model, dataloader, device, n_samples)** -> dict
   - For each sample:
     - Extract latent via model.encoder(batch)
     - Quantize latent
     - Compute BPP via compute_latent_bpp
     - Decode from quantized latent for quality metrics
   - Return dict with:
     - 'bpp_mean', 'bpp_std': aggregate BPP statistics
     - 'psnr_mean', 'psnr_std': quality from quantized reconstruction
     - 'ssim_mean', 'ssim_std': quality from quantized reconstruction
     - 'samples': list of per-sample (bpp, psnr, ssim)

2. **generate_jpeg2000_rd_curve(test_images, n_points=25)** -> pd.DataFrame
   - Quality range: 1 to 1000 (full JPEG-2000 range)
   - Log-space 25 quality points for even coverage
   - For each quality level:
     - Encode/decode all test images
     - Compute BPP = encoded_bits / input_pixels
     - Compute PSNR, SSIM
   - Return DataFrame with columns: quality, bpp, bpp_std, psnr, psnr_std, ssim, ssim_std

3. **interpolate_at_bpp(rd_curve, target_bpp)** -> dict
   - Use scipy.interpolate.interp1d on sorted R-D curve
   - Handle out-of-range BPP (return NaN with warning)
   - Return {'bpp': target_bpp, 'psnr': interp_psnr, 'ssim': interp_ssim, 'extrapolated': bool}

4. **plot_rd_curves(ae_results, jp2_rd_curve, output_dir, metric='psnr')**
   - Plot JPEG-2000 as continuous curve with error band
   - Plot autoencoder points as scatter markers
   - Different colors: ResNet (orange), Baseline (blue), JPEG-2000 (gray)
   - Add annotations showing model names
   - X-axis: BPP, Y-axis: PSNR or SSIM
   - Title: "Bitrate-Matched Rate-Distortion Comparison"
   - Save to output_dir/figures/rd_curve_bitrate_matched_{metric}.png

**Main Script Flow:**
1. Parse args (--output-dir, --n-samples default 200, --device)
2. Create output directories: data/, figures/, tables/
3. Load test data (same 200 samples as Phase 6)
4. Discover and load all 6 autoencoder checkpoints
5. For each autoencoder:
   - Call evaluate_autoencoder_bpp
   - Store results
6. Generate JPEG-2000 R-D curve (25 points)
7. For each autoencoder BPP, interpolate JPEG-2000 metrics
8. Save JSON files:
   - autoencoder_bpp.json: {model_name: {bpp, psnr, ssim, ...}}
   - jpeg2000_rd_curve.json: [{quality, bpp, psnr, ssim}, ...]
   - bitrate_matched_results.json: {model: {ae_bpp, ae_psnr, jp2_psnr_at_bpp, ...}}
9. Generate figures (PSNR and SSIM R-D curves)
10. Print summary table
