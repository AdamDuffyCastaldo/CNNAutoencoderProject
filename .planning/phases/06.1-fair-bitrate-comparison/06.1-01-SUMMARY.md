## Technical Details

### Quantization Approach

Per-channel quantization preserves precision better than global quantization:

```python
# Per-channel: each channel uses its own [vmin, vmax] range
for c in range(C):
    vmin, vmax = channel_data[:, c].min(), channel_data[:, c].max()
    quantized[:, c] = floor((data[:, c] - vmin) / (vmax - vmin) * 255)
```

### Entropy Estimation

Following learned compression literature (Balle et al.):

```python
# Histogram-based probability estimation
hist, _ = np.histogram(quantized_channel, bins=256, range=(0, 256))
prob = hist / hist.sum()
H = scipy.stats.entropy(prob, base=2)  # bits per symbol
total_bits = H * n_symbols + overhead_bits
```

### BPP Calculation

```
BPP = (sum(channel_entropy * channel_samples) + overhead_bits) / (B * input_H * input_W)
    = (sum(channel_entropy * B * 16 * 16) + 64 * C) / (B * 256 * 256)
```
